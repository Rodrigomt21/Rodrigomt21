## 🧠 O que eu faço

Trabalho com **IA generativa aplicada a processos** — construo agentes que resolvem problemas reais dentro de operações grandes, não demos bonitas que morrem no notebook.

Do outro lado, gosto do metal: **visão computacional rodando na borda**, em hardware limitado, sob condição real de campo. É onde a engenharia dói e onde eu mais aprendo.

<br>

## 🌧️ Projeto em destaque — CityRain

> Plataforma de monitoramento de chuva urbana com **edge computing + visão computacional**.

Nós de borda com câmera classificam intensidade de chuva em tempo real. A inferência é dividida: um **classificador binário roda na Jetson** (chuva / não chuva) e o modelo de **4 classes de intensidade roda no backend**, com agregação espacial hexagonal **H3** e validação contra as redes CGE-SP, INMET e CEMADEN.

<div align="center">

| Camada | Tecnologias |
|:--|:--|
| **Edge** | Jetson Nano · OpenCV · systemd · GPS UART |
| **Modelos** | PyTorch · MobileNetV3 · EfficientNet-B0 · ResNet-18 |
| **Backend** | FastAPI · PostgreSQL · H3 |
| **Frontend** | React · TypeScript |
